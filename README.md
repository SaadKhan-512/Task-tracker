# Task Tracker

## Description

A simple command-line Task Tracker built with Python. It allows users to add, update, delete, and manage tasks. All tasks are stored locally in a JSON file.

## Features

- Add tasks
- Update existing tasks
- Delete tasks
- Mark tasks as completed
- Store tasks in a JSON file

## Installation

1. Clone the repository.
2. Navigate to the project directory.
3. Run the program using Python.

## Usage

```bash
py main.py add "Buy groceries"
py main.py update 1 "Go to gym"
py main.py delete 2
```
