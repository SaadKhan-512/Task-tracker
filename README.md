# Task-tracker

# Project description:
A simple command-line Task Tracker built with Python. It allows users to add, update, delete, and manage tasks using a JSON file.

# Features
- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Store tasks in a JSON file

# Installation
1. Clone the repository.
2. Navigate to the project folder.
3. Run the program using Python.

# Usage:
py main.py add "Buy groceries"
py main.py update 1 "Go to gym"
py main.py delete 2

# Technologies Used
- Python
- JSON
